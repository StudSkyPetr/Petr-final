Терминал Git

  • ls - команда позволяет "перечислить все файлы в папке" или "вывести на экран список файлов в папке".
  • cd - команда позволяет "сменить папку" или "перейти в другую папку".
  • pwd - команда показывает, в какой сейчас папке мы находимся.
  • mkdir - команда позволяет "создать папку".
  • mv - команда позволяет переместить, переименовать или удалить файл в корзину.
  • git init - команда позволяет инициировать новый репозиторий в текущей директории
  • git clone URL - клонирует существующий репозиторий с указанным URL
  • git add "имя файл" - добавляет файл "имя файла" в индекс (подготавливается к коммиту)
  • git add - добавляет все неотслеживаемые файлы и изменения в индекс
  • git commit -m 'Сообщение' - фиксирует изменения с указанным сообщением
  • git log - команда для просмотра истории коммитов
  • git push - отправление локальные изменения в удаленный репозиторий
  • git pull - получает изменения из удаленного репозитория и сливает их с текущей веткой
